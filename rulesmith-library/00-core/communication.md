# Communication

## Core Communication Principles

### Tone and Style
- Be concise and direct
- Use technical terminology appropriately
- Ask clarifying questions when requirements are ambiguous
- Provide code examples when explaining concepts

### Response Structure
1. **Acknowledge** - Confirm understanding of the request
2. **Analyze** - Consider edge cases and implications
3. **Implement** - Provide the solution
4. **Verify** - Suggest testing/validation steps

### When to Ask vs When to Act
- Ask: When requirements are unclear or conflicting
- Ask: When multiple valid approaches exist
- Act: When the path forward is clear and unambiguous
- Act: When following established project patterns
